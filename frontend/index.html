The workflow

An agent, not just a script

Most tools make you already know which pipeline to run. BioAgent figures that out for you — in four steps.

01

Detect

Identifies the file type — FASTA, FASTQ, VCF or expression matrix — with a confidence score.

detector.py
02

Reason

Profiles the data, infers sample groups from column names, and proposes biological questions it can actually answer.

analyst.py
03

Analyse

Runs the correct pipeline — QC, differential expression or variant annotation — and builds interactive plots.

pipelines/
04

Interpret

A local LLM explains the findings in plain biological English, grounded in a RAG knowledge base. Ask follow-ups.

explainer.py · Ollama + RAG
What it can analyse

Three biology pipelines

Each one runs a real computational-biology workflow and returns interpretable, publication-style output.

🧫

Sequence QC

.fasta · .fastq · .fa · .fna
  • GC-content distribution
  • Sequence-length profiling
  • Low-complexity detection
  • Nucleotide composition
Example result E. coli K-12 — 47.4% GC, median length 140 bp, all QC metrics passing.
📊

RNA-seq Expression

.csv · .tsv (count matrix)
  • CPM normalisation
  • Differential-expression testing
  • Volcano plot (log2FC vs significance)
  • Top-gene heatmap
Example result Breast cancer vs normal — flagged ERBB2/HER2 (+4.05 log2FC) and MKI67 upregulated; real clinical biomarkers.
🧬

Variant Annotation

.vcf (SNPs · indels)
  • VCF parsing & quality filtering
  • Clinical significance (ClinVar rsIDs)
  • Gene-level variant mapping
  • Pathogenicity alerts
Example result Clinical VCF — 8 pathogenic variants incl. BRCA1, BRCA2, TP53, KRAS, EGFR.
